# MD Reader

خواننده‌ی سبک فایل‌های Markdown با C# و [Avalonia](https://avaloniaui.net/). برنامه روی **ویندوز، لینوکس، مک و اندروید** اجرا می‌شود و برای نمایش Markdown به مرورگر، WebView یا اینترنت نیازی ندارد.

## امکانات

- باز کردن فایل‌های `.md` (و `.txt`) با دکمه، میان‌بر یا کشیدن فایل روی پنجره (کشیدن فایل مخصوص دسکتاپ است)
- **فایل‌های اخیر و بازیابی نشست**: فایل‌های اخیراً باز‌شده در صفحه‌ی خالی فهرست می‌شوند و با باز کردن دوباره‌ی برنامه، تب‌های جلسه‌ی قبل هم برمی‌گردند
- هر فایل در **تب جداگانه** باز می‌شود: انتخاب چند فایل با هم، جابه‌جایی بین تب‌ها، بستن با ✕ یا `Ctrl + W`، و نگه‌داشتن جای اسکرول هر تب
- **جست‌وجو در سند** با `Ctrl + F`: همه‌ی نتیجه‌ها هایلایت می‌شوند و با `Enter` / `Shift + Enter` بین آن‌ها جابه‌جا می‌شوید
- **فهرست مطالب** از تیترهای سند در ستون کنار (دکمه‌ی «فهرست»، قابل خاموش/روشن و ماندگار): با کلیک روی هر تیتر به همان بخش می‌روید، و هنگام اسکرول تیتر بخش جاری در فهرست برجسته می‌شود
- **درصد مطالعه** و **زمان تقریبی مطالعه** در نوار وضعیت
- **کتابخانه**: یک پوشه را انتخاب کنید تا فایل‌های Markdown آن در ستون کنار فهرست شوند و بتوانید بین نام و متن همه‌ی فایل‌ها جست‌وجو کنید؛ نتیجه‌ها با شماره‌ی خط و قطعه‌متن اطراف تطابق (با برجسته‌شدن خودِ کلمه) نمایش داده می‌شوند و کلیک روی هر نتیجه همان فایل را باز می‌کند و به محل آن می‌رود. متن فایل‌ها یک‌بار ایندکس می‌شود و فقط فایل‌های تغییرکرده دوباره خوانده می‌شوند. در اندروید پوشه با انتخاب‌گر سیستم (Storage Access Framework) انتخاب می‌شود و تا پایان همان نشست باز می‌ماند
- **نشانک، یادداشت و ادامه‌ی مطالعه**: با `Ctrl + D` یا دکمه‌ی «نشانک‌ها» در نقطه‌ی فعلی نشانک بگذارید، یادداشت بنویسید و با کلیک روی هر کدام به همان نقطه برگردید. جای اسکرول هر فایل ذخیره می‌شود و با باز کردن دوباره، از همان‌جا ادامه می‌دهید. همه‌ی این‌ها در فایل کنار سند (`notes.md.mdreader`) ذخیره می‌شوند و خود فایل Markdown هرگز تغییر نمی‌کند
- **حالت تاریک**: تم روشن، تیره یا هماهنگ با سیستم؛ رنگ‌آمیزی کد و همه‌ی اجزای سند هم با تم عوض می‌شوند
- **زبان رابط (فارسی/انگلیسی)** و **جهت خودکار**: جهت سند از روی زبان متن تشخیص داده می‌شود و می‌توانید آن را روی راست‌به‌چپ یا چپ‌به‌راست قفل کنید
- **عرض متن** (باریک/معمولی/پهناور) و **حالت تمرکز** (`F11`) برای پنهان‌کردن نوارها
- **کپی و شماره‌خط بلوک‌های کد**: هر بلوک کد دکمه‌ی کپی و شماره‌ی خط دارد
- **نمایش تصاویر** سند (مسیرهای نسبی، مطلق و `data:`؛ به اینترنت وصل نمی‌شود)
- **رنگ‌آمیزی کد** در بلوک‌های کد برای زبان‌های رایج (C#، JS/TS، Python، Shell، SQL، HTML/XML، JSON و…)
- **بازخوانی خودکار**: اگر فایل روی دیسک تغییر کند، تب دوباره خوانده می‌شود (با سوییچ `--watch` هم روشن می‌شود)
- **باز کردن سریع** با `Ctrl + E`: بخشی از نام فایل را بنویسید و `Enter` بزنید؛ فایل‌های اخیر و کتابخانه با تطبیق حرف‌به‌حرف فیلتر می‌شوند
- **لینک بین فایل‌ها**: لینک نسبی مثل `[بخش بعدی](next.md)` یا `notes/idea.md#part` همان فایل را در تب جدید باز می‌کند (اول در پوشه‌ی سند، بعد در کتابخانه)
- **پانویس** با شماره و پیوند رفت‌وبرگشت به محل ارجاع، و نمایش فرمول‌های ریاضی (`$…$` و `$$…$$`) به‌صورت متن مونواسپیس
- **خروجی**: کپی متن به‌صورت **متن غنی** (برای چسباندن در Word، ایمیل و…) و **ذخیره به PDF**؛ روی دسکتاپ PDF متنی است (قابل انتخاب، جست‌وجو و خواندن با ابزارهای دسترس‌پذیری) و روی اندروید تصویری
- پرش به **لینک‌های داخلی** سند (`#heading`) بدون باز کردن مرورگر
- **دسترس‌پذیری**: دکمه‌های فقط-آیکون نام دسترس‌پذیری دارند (برای TalkBack و VoiceOver) و `F6` بین پانل‌های نشانک‌ها، کتابخانه، سند و فهرست می‌چرخد
- **پنل تنظیمات** پشت دکمه‌ی ⚙ در نوار ابزار (یا `Ctrl + ,`): فونت، اندازه، جهت، عرض متن، تم، زبان و بازخوانی خودکار یک‌جا؛ با `Escape` یا کلیک بیرون پنل بسته می‌شود؛ باز شدنش فوکوس را به اولین گزینه می‌برد، `Tab` بین کنترل‌های پنل می‌چرخد (از آخری به اولی) و بستنش فوکوس را به دکمه‌ی ⚙ برمی‌گرداند
- **ذخیره‌ی تنظیمات**: فونت، اندازه، جهت، تم، زبان، عرض متن و نمایش فهرست مطالب با بستن برنامه از دست نمی‌روند
- **فونت Vazirmatn همراه برنامه** (جاسازی‌شده) به‌عنوان فونت پیش‌فرض، تا متن فارسی روی همه‌ی سیستم‌ها و در اندروید یکسان دیده شود
- کلید **راست به چپ (RTL)** برای نمایش کامل سند از راست به چپ (فهرست‌ها، نقل‌قول‌ها و جدول‌ها هم قرینه می‌شوند و کد همیشه چپ‌به‌راست می‌ماند)
- انتخاب فونت از میان همه‌ی فونت‌های نصب‌شده‌ی سیستم؛ تغییر فونت روی کل فایل اعمال می‌شود
- تغییر اندازه‌ی فونت (همه‌ی بخش‌ها، از جمله تیترها و کد، متناسب بزرگ/کوچک می‌شوند)
- نمایش تیترها، متن ضخیم و مورب، خط‌خورده، کد درون‌خطی و بلوکی، فهرست ساده/شماره‌دار/وظایف، نقل‌قول، جدول، خط جداکننده و پیوندهای قابل کلیک
- انتخاب و کپی متن سند
- نوار وضعیت با تعداد کلمه و کاراکتر
- خواندن فایل‌های UTF-8 (با یا بدون BOM)، UTF-16 و فایل‌های قدیمی Windows-1256

## پیش‌نیاز

- **.NET SDK 8** برای ساخت نسخه‌ی دسکتاپ، یا **.NET 8 Runtime** برای اجرای نسخه‌ی وابسته به رانیتایم
- ویندوز ۱۰/۱۱، لینوکس (X11 یا Wayland) یا macOS 11 یا بالاتر
- برای ساخت اندروید: **.NET SDK 10**، ورک‌لود `android` و **JDK 17** (بخش [ساخت نسخه‌ی اندروید](#ساخت-نسخهی-اندروید))

## اجرا

```bash
dotnet run -- sample.md          # باز کردن یک فایل
dotnet run -- sample.md --rtl    # شروع با حالت راست‌به‌چپ روشن
dotnet run -- sample.md --watch  # بازخوانی خودکار هنگام تغییر فایل
dotnet run                       # بدون فایل (صفحه‌ی خالی یا تب‌های جلسه‌ی قبل)
```

ساخت و اجرای مستقیم:

```bash
dotnet build -c Release
./bin/Release/net8.0/MdReader sample.md      # لینوکس/مک
bin\Release\net8.0\MdReader.exe sample.md    # ویندوز
```

## انتشار برای هر سیستم‌عامل

فایل‌های اجرایی مستقل (بدون نیاز به نصب .NET روی سیستم مقصد):

```bash
dotnet publish -c Release -r win-x64   --self-contained true -o dist/win-x64
dotnet publish -c Release -r linux-x64 --self-contained true -o dist/linux-x64
dotnet publish -c Release -r osx-arm64 --self-contained true -o dist/osx-arm64
dotnet publish -c Release -r osx-x64   --self-contained true -o dist/osx-x64
```

اگر روی سیستم مقصد .NET 8 نصب است، `--self-contained false` حجم خروجی را کم می‌کند.

## ساخت نسخه‌ی اندروید

هد اندروید (`MdReader.Android/`) از Avalonia 12 استفاده می‌کند که فقط برای `net10.0-android` ساخته شده؛ پس برخلاف بقیه‌ی برنامه‌ها به **.NET SDK 10** نیاز دارد. یک‌بار ابزارها را نصب کنید:

```bash
dotnet workload install android   # چند گیگابایت فضا و احتمالاً دسترسی ادمین/root می‌خواهد
java -version                     # باید JDK 17 باشد
```

سپس:

```bash
dotnet publish MdReader.Android/MdReader.Android.csproj -c Release -f net10.0-android \
    -p:AndroidPackageFormats=apk -o out/android
```

خروجی: `out/android/com.smrmoosavi.mdreader-Signed.apk`. برای نصب روی گوشی، «نصب از منابع نامشخص» را برای فایل‌منیجر یا مرورگر اجازه بدهید و APK را باز کنید. اجرا روی گوشی/امولاتور وصل‌شده هم ممکن است:

```bash
dotnet build MdReader.Android/MdReader.Android.csproj -t:Run -f net10.0-android
```

تنظیمات فعلی: package id `com.smrmoosavi.mdreader`، حداقل اندروید ۷ (API 24)، خروجی APK و امضا با کلید debug (برای نصب دستی کافی است).

در اندروید دکمه‌ی «کتابخانه» هم کار می‌کند: پوشه با `ACTION_OPEN_DOCUMENT_TREE` انتخاب می‌شود و فایل‌ها از طریق Storage Access Framework خوانده می‌شوند (بدون نیاز به مسیر فایل). برنامه دسترسی ماندگار (`takePersistableUriPermission`) را درخواست می‌کند و نشانی پوشه را در تنظیمات نگه می‌دارد، بنابراین پوشه در نشست بعد دوباره باز می‌شود؛ اگر ارائه‌دهنده‌ی فایل این دسترسی را ندهد، مثل قبل باید پوشه را دوباره انتخاب کنید. نشانک، یادداشت و جای مطالعه‌ی فایل‌هایی که با SAF باز می‌شوند هم در پوشه‌ی داده‌ی برنامه (کلید‌شده با URI سند) ذخیره می‌شوند، نه کنار فایل. برای انتشار در Google Play باید keystore بسازید، `AndroidKeyStore` و کلید امضا را در `MdReader.Android.csproj` تنظیم کنید و خروجی را به AAB تغییر بدهید.

باز کردن فایل در اندروید با انتخاب‌گر فایل سیستم انجام می‌شود و محتوا از استریم خوانده می‌شود (نه از مسیر فایل)، بنابراین با scoped storage اندروید سازگار است؛ دکمه‌ی «بازخوانی» هم همان فایل انتخاب‌شده را دوباره می‌خواند. کشیدن فایل روی پنجره فقط در دسکتاپ معنی دارد.

## تنظیمات و فایل‌های ذخیره‌شده

تنظیمات در `%APPDATA%/MD Reader/settings.json` (ویندوز) یا مسیر هم‌ارز آن در لینوکس/مک/اندروید نگه‌داری می‌شود؛ قالبش خط‌های ساده‌ی `key=value` است: `font`، `size`، `direction` (`auto`/`rtl`/`ltr`)، `theme` (`system`/`light`/`dark`)، `language` (`fa`/`en`)، `width` (`narrow`/`normal`/`wide`)، `outline`، `autoreload`، `library`، `libraryuri` (نشانی پوشه‌ی کتابخانه در اندروید)، و لیست‌های `recent`/`session`.

### خروجی PDF

روی دسکتاپ PDF با [QuestPDF](https://www.questpdf.com/) از همان Markdown ساخته می‌شود، پس متن واقعی دارد (قابل انتخاب و جست‌وجو) و فارسی با فونت همراه برنامه (Vazirmatn) شکل می‌گیرد؛ فونت Vazirmatn کنار فایل اجرایی هم کپی می‌شود تا موتور PDF آن را پیدا کند. کد QuestPDF با مجوز Community استفاده می‌شود (رایگان برای سازمان‌های زیر یک میلیون دلار درآمد سالانه)؛ اگر شرایط مجوز شما فرق دارد، این وابستگی را جایگزین کنید. روی اندروید، جایی که موتور متنی در دسترس نیست، همان خروجی تصویری قبلی استفاده می‌شود.

نشانک‌ها، یادداشت‌ها و جای مطالعه در فایل کنار هر سند (`<نام فایل>.mdreader`) ذخیره می‌شوند؛ خود فایل Markdown تغییر نمی‌کند و فایل اضافی دیگری هم ساخته نمی‌شود. اگر پوشه فقط‌خواندنی باشد، برنامه بی‌صدا از ذخیره‌ی آن صرف‌نظر می‌کند.

## نصب روی ویندوز (برنامه‌ی نصب)

پوشه‌ی `Installer/` یک برنامه‌ی نصب کوچک (WPF، مخصوص ویندوز) است که نسخه‌ی منتشرشده‌ی برنامه را در خود جاسازی می‌کند:

```powershell
powershell -ExecutionPolicy Bypass -File Installer\build-installer.ps1
```

خروجی: `Installer\dist\MdReaderSetup.exe`. با اجرای آن:

- برنامه در `%LOCALAPPDATA%\Programs\MdReader` نصب می‌شود (بدون نیاز به دسترسی ادمین)
- برنامه به‌عنوان بازکننده‌ی فایل‌های `.md`، `.markdown` و `.mdown` ثبت می‌شود و آیکون فایل‌ها به آیکون MD Reader تغییر می‌کند
- میان‌بر منوی استارت (و به‌صورت اختیاری دسکتاپ) ساخته می‌شود
- برنامه در **Settings → Apps → Installed apps** فهرست می‌شود و از همان‌جا (یا با `Uninstall.exe`) حذف می‌شود

سوییچ‌های خط فرمان نصب‌کننده (برای نصب/حذف بی‌صدا):

```text
MdReaderSetup.exe [--install|--uninstall] [--silent] [--dir <path>] [--ext .md]
                  [--no-associate] [--no-shortcuts] [--desktop] [--from-temp]
```

## ثبت به‌عنوان بازکننده‌ی فایل‌های Markdown در لینوکس و مک

در **macOS** آرشیو ریلیز به‌صورت `MdReader.app` است و `Packaging/Info.plist` نوع سند Markdown را اعلام می‌کند؛ پس از بیرون آوردن برنامه، روی یک فایل `.md` راست‌کلیک کنید → **Open With** → MD Reader (یا با `open -a MdReader file.md`). برنامه امضای کد Apple ندارد، بنابراین بار اول ممکن است لازم باشد روی برنامه راست‌کلیک → **Open** بزنید.

در **لینوکس** فایل `mdreader.desktop` همراه آرشیو می‌آید؛ آن را در جای مناسب بگذارید و مسیر `Exec` را اصلاح کنید:

```bash
cp mdreader.desktop ~/.local/share/applications/
sed -i "s|Exec=MdReader|Exec=/path/to/MdReader|" ~/.local/share/applications/mdreader.desktop
xdg-mime default mdreader.desktop text/markdown
```

در **اندروید** برنامه برای اکشن‌های `VIEW` و `SEND` روی `text/plain` و `text/markdown` ثبت شده است، بنابراین از فایل‌منیجر یا منوی «ارسال به» هم می‌توانید فایل را در MD Reader باز کنید.

## ساختار پروژه

- `Directory.Build.props` — تنها جای تعریف **شماره‌ی نسخه**؛ دسکتاپ، کتابخانه‌ی مشترک، اندروید و نصب‌کننده‌ی ویندوز از همین می‌خوانند
- `MdReader.csproj` / `Program.cs` — هد دسکتاپ (بخش فقط‌ویندوز/دسکتاپ برنامه)
- `MdReader.Shared/` — کتابخانه‌ی مشترک: `App.axaml` (تم‌ها و استایل‌ها)، `MainView.axaml(.cs)` (کل رابط کاربری)، `AppSettings.cs` (تنظیمات، فایل‌های اخیر و نشست)، `AppTheme.cs` (تم)، `TextDirection.cs` (تشخیص جهت)، `TextLoader.cs` (تشخیص انکودینگ)، `ExternalOpen.cs` (فایل‌هایی که سیستم‌عامل به برنامه می‌دهد)، `RemoteAccess.cs` (قلاب اندروید برای نگه‌داشتن دسترسی به پوشه)، `LibraryScanner.cs` + `LibraryIndex.cs` (پیمایش پوشه، ایندکس و جست‌وجوی محتوا)، `ReadingState.cs` (نشانک، یادداشت و جای مطالعه، برای فایل‌های دارای مسیر و بدون مسیر)، `Localization/` (دیکشنری‌های رشته‌های فارسی و انگلیسی + `Lang.cs`)، `Rendering/` (رندرکننده، پالت روشن/تیره، بارگذار تصویر و رنگ‌آمیزی کد)، `Export/` (`PdfExporter` انتخاب‌کننده، `PdfTextExporter` برای دسکتاپ، `PdfImageExporter` برای اندروید و متن غنی) و `assets/` (آیکون و فونت همراه در `assets/fonts/`)
- `Packaging/` — `mdreader.desktop` برای لینوکس و `Info.plist` برای بسته‌ی `.app` مک (workflow آن‌ها را در آرشیوها می‌گذارد)
- `MdReader.Android/` — هد اندروید: `MainActivity`، مانیفست، آیکون و تم
- `Installer/` — برنامه‌ی نصب ویندوز (پروژه‌ی جدا؛ در ساخت برنامه‌ی اصلی نادیده گرفته می‌شود)

رابط کاربری در `MainView` است، بنابراین دسکتاپ (پنجره) و اندروید (تک‌ویو) همان کد را اجرا می‌کنند. پنجره‌ی دسکتاپ و آیکونش در `MdReader.Shared/App.axaml.cs` ساخته می‌شوند و `MainWindow` جداگانه‌ای وجود ندارد.

## انتشار خودکار با GitHub Actions

Workflow در `.github/workflows/release.yml` با هر تگ اجرا می‌شود و برای هر سه سیستم‌عامل خروجی مستقل می‌سازد:

```bash
git tag v1.0.0
git push origin v1.0.0
```

نتیجه در صفحه‌ی **Releases** همان تگ قابل دانلود است:

- `MdReaderSetup.exe` — برنامه‌ی نصب ویندوز (از نسخه‌ی win-x64 ساخته می‌شود)
- `MdReader-win-x64.zip`
- `MdReader-linux-x64.tar.gz`
- `MdReader-osx-arm64.tar.gz` (مک با پردازنده‌ی Apple Silicon؛ شامل `MdReader.app`)
- `MdReader-osx-x64.tar.gz` (مک با پردازنده‌ی Intel؛ شامل `MdReader.app`)
- `com.smrmoosavi.mdreader-Signed.apk` (اندروید؛ با کلید debug امضا شده و برای نصب دستی کافی است)

این نسخه‌ها self-contained هستند و به نصب .NET روی سیستم مقصد نیازی ندارند. اجرای دستی هم از **Actions → Release → Run workflow** ممکن است (بدون ساخت Release، فقط artifact).

APK اندروید در یک job جداگانه روی `ubuntu-latest` ساخته می‌شود: نصب ورک‌لود `android` + JDK 17 روی SDK 10، سپس `dotnet publish` با `AndroidPackageFormats=apk`.

`MdReaderSetup.exe` در یک job جداگانه روی `windows-latest` ساخته می‌شود: ابتدا نسخه‌ی win-x64 منتشر و به‌عنوان `payload.zip` در نصب‌کننده جاسازی می‌شود، سپس `Installer/Installer.csproj` (WPF، هدف `net10.0-windows`) به یک فایل اجرایی تک‌فایلی تبدیل می‌شود. این job از **.NET SDK 10** استفاده می‌کند، در حالی که خود برنامه با SDK 8 ساخته می‌شود.
